# 數值規則與搜尋行為

這份文件保留網站的完整數值契約。Python CLI 與瀏覽器版本使用相同規則；Python 也是瀏覽器 fixtures 的參考實作。

## 輸入與精度

- `initial`、`ratio` 只接受一般十進位正數，格式為 `[0-9]+(?:\.[0-9]+)?`。
- 拒絕零、負數、正負號、科學記號、`NaN`、`Infinity`、`.5`、`1.` 等格式。
- `initial` 只去除首尾空白；原始字串與尾端零保留。
- `d` 是原始輸入的小數位數，包含尾端零：

| initial | d | step |
| --- | ---: | ---: |
| `"0.1"` | 1 | `0.1` |
| `"0.10"` | 2 | `0.01` |
| `"0.100"` | 3 | `0.001` |
| `"0.01"` | 2 | `0.01` |
| `"0.165"` | 3 | `0.001` |
| `"0.1650"` | 4 | `0.0001` |
| `"1"` | 0 | `1` |

`"0.1"`、`"0.10"`、`"0.100"` 的數值相同，但搜尋精度不同，不可正規化成同一個設定。

## 候選與 target

```text
step = 10^(-d)
x = initial + k * step        （k 為非零整數）
```

- `initial` 不列入候選；下調只保留 `x > 0`。
- 以整數格點建立候選，不使用浮點累加。
- `TARGET_DECIMALS = null` 時，target 使用 `d`；可覆寫為非負整數。
- `target` 是將未經顯示捨入的精確 `y`，以 `ROUND_HALF_UP` 捨入到 `target_decimals` 位。
- `target = 0` 的候選安全跳過，不計算除以零的 discrepancy。

## discrepancy 與合格判斷

```text
discrepancy_percent = abs(y - target) / abs(target) * 100
p = max(d - 1, 0)
合格 ⇔ discrepancy_percent < 0.5 * 10^(-p)
```

- discrepancy 已經是百分比，不再乘以 100。
- 合格判斷使用精確有理數交叉相乘，嚴格小於；等於邊界不合格。
- `p` 位顯示使用 `ROUND_HALF_UP`，但顯示值不參與合格判斷。
- 顯示為 `0.00%` 不代表精確誤差等於零；`≈` 表示顯示值非精確值。
- `d = 3`（`p = 2`）時：`0.0049%` 合格、`0.0050%` 不合格。

## 顯示

- 候選 `x` 與 `x - initial` 固定顯示 `d` 位小數，保留尾零。
- target 使用既有簡潔格式，移除多餘尾零（例如 `0.560` 顯示為 `0.56`），但計算精度仍是 `target_decimals`。
- 四捨五入後的 discrepancy 固定顯示 `p` 位小數並加上 `%`。
- 循環小數或超出顯示精度的值標示 `≈`；顯示格式不會改變合格判定。

## 搜尋、停止與排序

- 預設每方向安全上限 `MAX_SEARCH_STEPS = 1,000,000`；`RESULT_LIMIT = 3`。
- 上下方向各自從 `initial ± step` 開始逐格向外搜尋。
- 每方向找到 `RESULT_LIMIT` 個合格候選就停止，不用另一方向補足。
- 下調遇到下一個非正數格點就停止，這與安全上限是不同的停止原因。
- 達安全上限仍不足時，UI 顯示「已達搜尋安全上限」，不宣稱全域無解。
- 候選依距離 `initial` 由近到遠；各方向獨立排序。
- 每次搜尋只代表本次有限步數內的結果。

## 預設值與進階設定

網站與 Python 的預設值一致：

```text
MAX_SEARCH_STEPS = 1,000,000
RESULT_LIMIT = 3
TARGET_DECIMALS = null（使用 d）
```

為了瀏覽器資源，網站 UI 明確限制並顯示：

- 每方向最大步數：`1–2,000,000`（預設 `1,000,000`）。
- 每方向結果筆數：`1–20`（預設 `3`）。
- target 小數位數：留空（使用 `d`）或 `0–100`。

超過上限會顯示錯誤，不會自動截斷或改值。

## 必驗案例

`initial = "0.165"`、`ratio = "3.1818"`、multiply：

- initial 本身：`y = 0.524997`、`target = 0.525`、`discrepancy ≈ 0.0005714286%`、`p = 2`、顯示 `0.00%`、合格。
- `x = 0.176`：`y = 0.5599968`、`target = 0.56`、同樣合格。
- target 精度是 `d = 3`，不是 `p = 2`。
